# GitHub公開手順

1. このGitHub公開用ZIPを展開します。
2. GitHubで空のRepositoryを作成します（例: `ChatGPT-Bundle-Framework`）。
3. 展開したRepositoryフォルダの**中身全部**をアップロードします。
4. Repository直下に `README.md` と `LICENSE` が見える状態にします。
5. Commit message例: `Initial public release: v0.11`
6. GitHub Releaseを作る場合、Tagは `v0.11`、Release assetには `releases/ChatGPT_Bundle_Framework_v0.11.zip` を指定します。

ライセンスはMITです。
